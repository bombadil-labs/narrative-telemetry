# Demos

The worked corpus lives here. Proposed first corpus: ***Dracula*** (see README.md — public
domain, and already structured as diaries, letters, telegrams, and phonograph transcripts from
half a dozen narrators who don't fully trust each other; narrative-telemetry-shaped before we
touch it).

Planned layout, in the shape of loam's `demos/village/`:

- `dracula/` — the canonical store's register files and ingest scripts
- `povs/` — sovereign point-of-view stores (Mina, Seward, …)
- `readers/` — confluence stores serving the comparative lenses (`DramaticIrony`, …)
- a dashboard in the shape of the village's `dashboard.html`
